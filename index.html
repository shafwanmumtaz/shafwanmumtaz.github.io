Keahlian & Alat Kerja

Alat dan metode yang saya gunakan sehari-hari dalam pengerjaan studi kasus data maupun administrasi operasional.

Python & Data Mining

  • Pandas & NumPy: pembersihan missing value, konversi tipe data, dan agregasi.
  • Matplotlib & Seaborn: visualisasi distribusi dan tren eksploratif.
  • Scikit-learn & CLI: dasar klasifikasi/klastering serta otomasi file (os, shutil).

Excel & SQL

  • Microsoft Excel: Pivot Table lintas departemen, standarisasi teks (TRIM, PROPER, TEXT), serta fungsi logika (IF, COUNTIF).
  • SQL: penulisan query seleksi, penggabungan tabel (JOIN), dan agregasi data.
  • Pelaporan: penyusunan rekap periodik yang siap diaudit.

Operasional & Kolaborasi
